4. Local Data Storage Architecture (Android SharedPreferences)

To preserve your game state across gameplay sessions, Arrow Escape Quest utilizes Android's native, sandboxed, operating-system-level key-value storage engine known as SharedPreferences.

4.1 What Exact Data Is Stored Locally?

All stored keys are non-personal, strictly operational, and entirely localized to your physical device. The following parameters are maintained:

  • saved_level (Integer): Represents the highest numerical level currently unlocked by the player (e.g., Level 1, Level 15).
  • stars_level_{X} (Integer): Records the star rating (1, 2, or 3 stars) earned upon completing a specific level number.
  • sound_enabled (Boolean): Stores your preference for in-game sound effects (toggle state: true or false).
  • music_enabled (Boolean): Stores your preference for calming background musical themes (toggle state: true or false).
  • haptic_enabled (Boolean): Stores your preference for device vibration effects on puzzle taps (toggle state: true or false).
  • theme_mode (String): Remembers visual UI appearance preferences (e.g., Light or Dark UI theme).

4.2 Where Is This Data Stored & Who Has Access?

This data is written exclusively to an internal XML file inside the Application's private, operating-system-sandboxed directory on your physical device: /data/data/com.choco.animation.arrow/shared_prefs/game_prefs.xml.

Under Android's Linux user-isolation architecture, no third-party application, website, or external actor can access, read, or inspect this sandboxed file. Furthermore, the Application has no cloud backup, remote database, or synchronization server. The data never leaves your physical device.

4.3 How Can You Erase or Reset This Data?

You maintain absolute ownership and control over all localized gameplay records at all times:

  • In-Game Reset: Navigate to Settings within the Game and select "Reset Progress". Confirming this action will immediately overwrite and wipe all level milestones, returning your progress to Level 1.
  • Android System Clear: Go to your device's Settings > Apps > Arrow Escape Quest > Storage > Clear Storage / Clear Data to instantly eradicate the local preferences file.
  • Uninstallation: Uninstalling the Application automatically causes the Android operating system to permanently delete the entire private sandboxed directory and all associated files.

9. Security Standards & Code Hardening

Although the Application operates in an offline capacity, we have taken extensive engineering measures to harden the codebase:

  • ProGuard / R8 Obfuscation: The entire production binary is compiled with aggressive code shrinking and repackaging rules, stripping source file metadata and variable names to protect system integrity.
